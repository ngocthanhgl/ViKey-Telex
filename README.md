# ViKey — Bàn phím Telex Tiếng Việt cho Android

Vikey tập trung vào **bộ gõ thuần** như **Unikey** hay **EVKey** trên desktop — phản hồi tức thì, không delay như Gboard hay SwiftKey vốn có AI và ML chạy ngầm.

Các tính năng như gợi ý từ, theme, glide typing chỉ là phụ, không phải trọng tâm. Vì tập trung vào gõ thuần nên Vikey khá kén người dùng.

## Quyền Riêng Tư

**Zero network access. Zero tracking. Zero analytics.** Mọi thao tác gõ phím ở lại trên máy bạn — không Internet, engine + từ điển local 100%. Nhưng với người thích Privacy thì Vikey hoàn toàn là lựa chọn phù hợp nhất ngoài kia.
