Dictionary Data License Information
====================================

1. English wordlist and bigrams
   Source: OpenBoard / AOSP `en_wordlist.combined`
   https://github.com/openboard-team/openboard/blob/v1.4.5/dictionaries/en_wordlist.combined.gz
   Repackaged by the HeliBoard dictionary repository:
   https://codeberg.org/Helium314/aosp-dictionaries
   License: Apache License, Version 2.0.

2. Vietnamese wordlist and bigrams
   Source: HeliBoard `main_vi__experimental.combined`
   https://codeberg.org/Helium314/aosp-dictionaries
   Built from word lists from the Leipzig Corpora Collection:
   https://wortschatz.uni-leipzig.de/en/download/
   License: Creative Commons Attribution 4.0 International (CC BY 4.0).

Both files were converted to ViKey's JSON format by
`scripts/generate_keyboard_dicts.py`. The `.combined` `f=` field is an AOSP
log-frequency; it is converted to a monotonic integer count. Bigram `f=1..3`
is a rank and becomes a relative count.

The original `.combined` files are not bundled; download them from the URLs
above and rerun the script if you need to regenerate the dictionaries.
